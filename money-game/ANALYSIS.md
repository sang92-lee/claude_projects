# "80억 분의 1" 분석과 머니게임 설계

## 무엇인가 (확인됨)
- 이름이 같은 다른 게임은 찾지 못했고, 2026년 10월 5일 공개된 무료 웹 인생 시뮬레이션 1in8b.life로 판단.
- 한국 1인 개발자(Jin Hwi-eus)가 Claude로 약 4시간 만에 제작. 글자 위주.
- 나라·부모는 고를 수 없음. 실제 공개 통계(UN, WHO, 세계은행 등) 기반. 공식 사이트 기준 172개 국가·지역(이전 버전 기사는 141개).
- 해마다 집중 분야 선택, 갈림길 결정. 수치는 확률만 바꿀 뿐 결과를 정하지 않음.
- 같은 초에 태어난 4명을 나란히 보여 줌. 점수·순위 없음. 죽으면 기록과 공유 카드 생성.
- 10년 남짓마다 불황·위기가 오고 자산 투자를 고를 수 있음(Business Insider Japan 체험기).

## 왜 퍼졌나
확인: SNS에 "두 번째 인생" 결과와 인상 깊은 이야기가 잇따라 올라옴. 제작 과정 Threads 공유가 출발점. 유명인 후기. 출생 환경의 힘을 체감한다는 평.
내 해석(추측): ①설치·가입 없음 ②내 인생이 아니라 부담 없이 자랑 ③무작위라 결과가 전부 달라 글감이 됨 ④"실제 데이터"가 신뢰와 뒷맛을 줌 ⑤다음엔 어디서 태어날지 궁금해 재도전.
약점: 30분~1시간으로 길고, 후반이 비슷하다는 비판 있음.

## 머니게임에 옮긴 것
| 원작 | 머니게임 |
|---|---|
| 출생국 무작위, 실제 통계 | 세계은행 2022 출생 수 비례로 198개국 추첨. 소득·수명도 실제 값 |
| 같은 초의 4명 | 같은 1초에 태어난 4명과 돈 경주 |
| 위기 주기 | 10년마다 분위기를 읽고 금고/씨앗밭/로켓 선택 |
| 공유 카드 | 결과 카드, 같은 출발선 친구 대결 링크, 오늘의 5명 |
| 긴 플레이 | 터치 7번 이하, 1분 안쪽 |
원작은 순위를 일부러 뺐지만, 머니게임은 순위를 재미의 중심으로 삼음(사용자 요청의 차이).

게임 안 배수·확률과 "1인당 벌이를 그대로 저축"은 재미용 단순화이며 실제 수익률이 아님.
